# Third-party notices

Design Harness is informed by the interaction model of
[Huiyuhere/design-canvas](https://github.com/Huiyuhere/design-canvas), an
MIT-licensed project. The concepts carried forward include an infinite canvas,
route frames, DOM selection, route graphs, and frame virtualization. Agent
Harness uses a new implementation and replaces Design Canvas's temporary
override/export workflow with validated source transactions and inverse patches.

See each dependency's package metadata for its license.
